--- SCIENTIFIC BIAS & REDUNDANCY ANALYSIS ---

1. FEATURE DOMINANCE AND SHORTCUT LEARNING
   In Experiment A, 'productivity_score' dominates Gini importance of the decision tree.
   Because 'productivity_score' is an engineered feature derived directly from 'wpm' and 'errors',
   it acts as a compressed proxy for the rule-based fatigue label itself. The decision tree classifier
   learns a 'shortcut' by splitting almost exclusively on 'productivity_score', rendering raw behavioral
   and physical eye telemetry features virtually useless in training. This makes the model extremely
   vulnerable if there are shifts in typing characteristics or if keyboard telemetry is absent.

2. ADVANTAGE OF RANDOM FOREST ENSEMBLE OVER SINGLE DECISION TREE
   Single decision trees make greedy choices, leading to extreme splits on single variables.
   Under Decision Tree B, WPM and Errors still monopolize Gini importances (over 90% combined).
   By contrast, the Random Forest Ensemble uses random feature bagging, forcing individual trees to
   train on physical coordinate variables. As shown in the Gini importances, physical telemetry features
   (eye_aperture, mouth_stretch) receive significantly higher weight under the Random Forest. This creates
   a much more robust, balanced multimodal system that is resilient to sensor connection drops.

3. REAL-WORLD GENERALIZATION AND MULTI-MODAL ROBUSTNESS
   Random Forest achieves high generalization. More importantly,
   it distributes Gini importance across both behavioral keyboard features (wpm, errors) and physiological
   features (eye_aperture, mouth_stretch). This ensures the model remains robust in real-world scenarios. For example,
   if the user is silently reading or watching a video (WPM = 0, no errors), the model can still predict
   fatigue based on physical eye openness/yawn telemetry. Conversely, if the camera is covered, keyboard telemetry
   provides strong indicators. Generalization is significantly improved.

4. DANGER OF SYNTHETIC-ONLY DATASETS & PERFECT CLASS SEPARATION
   Synthetic-only datasets often contain artificial, sharp boundaries that allow models to achieve 100% accuracy.
   This is dangerous because real human fatigue is continuous and varies by individual. By incorporating the real
   JzZJUT eye-tracking dataset and injecting Gaussian noise, we introduce overlapping class distributions.
   Perfect accuracy is suspicious and usually signals data leakage. Achieving 80%-95% accuracy indicates a realistic,
   research-grade classifier that accepts human variance and is suitable for production.

--- PRODUCTION RECOMMENDATION ---
   We strongly recommend using the Random Forest Ensemble configuration (WITHOUT productivity_score as a feature)
   for the final machine learning classifier. The 'productivity_score' should still be calculated and displayed
   in the dashboard frontend as a high-value user metric, but it should not be fed as a feature into the fatigue
   prediction model. This resolves the feature dominance issue, removes hidden collinearity, and forces
   the model to learn true multimodal physical-behavioral interactions.
