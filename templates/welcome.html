System Capabilities

Built for Real-World Integration

A breakdown of the underlying engines that make FatigueAI a robust, startup-grade platform.

⌨️ Live Typing Metrics

Continuous collection of Words-Per-Minute and backspace frequency through a secure background hook.

📷 Facial Landmark Mesh

Uses MediaPipe FaceMesh to map face orientation and calculate exact spatial coordinate dimensions.

👁️ Blink & Yawn Trackers

Calculates dynamic Eye Aspect Ratio (EAR) and Mouth Aspect Ratio (MAR) to monitor physiological state changes.

🌲 Random Forest Ensemble

Features a co-trained classifier that achieves balanced predictions and resists camera dropouts.

🔍 Explainable Diagnostics

XAI engine translates numerical models into clear, actionable advice to help users manage burnout.

🔬 Research Exporters

Calculates real-time Pearson correlations ($r$) for biometric indicators and exports full session data.

🌓 Dark & Light Modes

Designed with glassmorphic cards and glowing visual palettes that match system theme controls.

🛠️ Boot Diagnostics

Checks system packages, SQLite schema, model files, and webcam ports during server startup.

💾 Isolated SQL Storage

Isolates user session telemetry databases, keeping profile metrics and generated CSV logs secure.

💡 Graceful Fallback

Bypasses ML predictors if hardware or classifiers are missing, switching to rules-based heuristics.

Computer Vision

Physiological Video Telemetry

Using 468 3D landmarks from MediaPipe FaceMesh, the webcam processor calculates EAR and MAR ratios dynamically.

👁️ Eye Aspect Ratio (EAR)

Tracks blink frequency and duration. Significant drops indicate micro-sleep warnings.

👄 Mouth Aspect Ratio (MAR)

Measures vertical mouth stretch. Detects yawns to track early physical fatigue.

Data Science

Pearson Correlation Analysis

The system evaluates linear correlations between keyboard speed, error rates, eye aperture, and fatigue levels:

r = Σ((x - x̄)(y - ȳ)) / √(Σ(x - x̄)² Σ(y - ȳ)²)

These metrics show how closely a user's typing metrics align with physiological fatigue markers.
